# Организация корпоративных мероприятий в VR

Репозиторий содержит программную реализацию алгоритмов для 3 этапа учебной практики.

## Описание
В данном проекте реализованы следующие алгоритмы:
1. Генерация и проверка криптографических токенов доступа к мероприятию.
2. Процедурная генерация конфигурации виртуальной комнаты на основе шаблонов.
3. Система проведения голосований и опросов в реальном времени.

## Технологический стек
- Язык: Python 3.8+
- База данных: SQLite (встроенная)
- Инструменты: Git, GitHub, Visual Studio Code

## Как запустить
1. Убедитесь, что у вас установлен Python.
2. Откройте терминал в папке с проектом.
3. Запустите файл командой:
   ```bash
   python vr_tests.py
4. В консоли отобразятся результаты автоматического тестирования всех модулей.
