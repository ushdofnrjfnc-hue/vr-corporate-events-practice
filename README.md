# Организация корпоративных мероприятий в VR

Репозиторий содержит программную реализацию для учебной практики.

Проект посвящён разработке программного модуля для организации корпоративных совещаний в виртуальной реальности. Модуль решает три ключевые задачи: генерация защищённых токенов доступа к мероприятию, процедурное построение конфигурации виртуальной комнаты из шаблона и проведение голосований по вопросам повестки.

## Структура проекта

### Этап 3. Аналитический (процедурная реализация)

- `vr_tests.py` — процедурная реализация алгоритмов генерации токенов, построения виртуальных комнат и проведения голосований. Включает модульные тесты для проверки корректности работы всех алгоритмов.

### Этап 4. Объектно-ориентированный и организационный

- `vr_oop.py` — объектно-ориентированная версия того же функционала. Содержит классы `InvitationManager`, `VirtualRoomBuilder`, `PollManager` и классы данных (`Vector3`, `VRObject`, `VirtualRoomConfig`). Включает модульные тесты, обработку исключений и валидацию входных параметров.
- `java-module/RoomConfigValidator.java` — вспомогательный модуль на языке Java для валидации JSON-конфигурации виртуальной комнаты перед сохранением. Демонстрирует владение объектно-ориентированным программированием на Java.
- `java-module/json-20240303.jar` — библиотека `org.json` для парсинга JSON (зависимость Java-модуля).

## Технологический стек

- **Python 3.8+** — основной язык реализации (стандартная библиотека: `sqlite3`, `hashlib`, `secrets`, `dataclasses`, `enum`, `json`).
- **Java 11+** — дополнительный модуль валидации конфигурации.
- **Git, GitHub** — система контроля версий и удалённое хранение кода.
- **Visual Studio Code** — среда разработки.
